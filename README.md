# 🎮 GameScreenTranslator (GameTranslator ID)

Penerjemah Subtitle Video Game ke Bahasa Indonesia secara *Real-Time* tanpa perlu menginstal mod game!

## 🚀 Fitur Utama
- **Tanpa Mod Game**: Aman tanpa membongkar file game.
- **3 Modus Tangkapan Layar**: Area Spesifik (Manual Snip), Auto Subtitle Zone (Area Bawah Layar), & Deteksi Otomatis Seluruh Layar.
- **Overlay 100% Transparan**: Teks terjemahan melayang bening tanpa background box.
- **Tinggi Box Otomatis (Dynamic Height)**: Mengembang ke bawah secara otomatis saat teks dialog panjang (multi-baris).
- **Pembersihan Teks Instan**: Cache dan teks overlay dibersihkan otomatis saat terjemahan di-pause.
- **Dua Mesin OCR**: Windows Native OCR (super cepat) & RapidOCR (offline ONNX model).

## 🛠️ Cara Menggunakan
1. Jalankan `Buka_GameTranslator.vbs` (atau `Buka_GameTranslator.bat`).
2. Atur modus deteksi layar & tampilan subtitle.
3. Klik **▶ MULAI MENTERJEMAHKAN** dan nikmati game Anda dalam Bahasa Indonesia!
